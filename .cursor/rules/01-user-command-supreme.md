# 最高指导原则：零弹窗与用户指令第一要素规则 (Zero-Prompt & Supreme Command Rule)

## 一、 绝对禁止触发 IDE 授权弹窗 (Zero-Prompt Iron Rule)

1. **彻底禁绝 `run_shell_command` (PowerShell)**：
   - **绝对禁止调用 `run_shell_command` 命令！** 所有会导致 IDE 向用户弹出“批准/授权”确认框的操作都是严重不合格的！
2. **100% 使用内置静默文件工具**：
   - 所有的代码编写、文件更新、配置读写与规则导出，必须 **100% 仅使用 `write_file`、`replace_file_content` 和 `read_file` 这三个内置工具静默完成**，不给用户制造任何点击弹窗的骚扰！

## 二、 用户指令第一要素与答复优先 (Answer-First Always)

1. **用户指令为唯一最高指示**：Agent 在任何情况下，必须 100% 严格无条件遵循用户下达的指令，绝不允许自作主张、凭空想象、盲目自信或擅自添加多余逻辑。
2. **未见回复文本前，绝对禁止修改代码**：
   - 当用户提出疑问、询问原因、下达排查分析任务时，Agent **必须 100% 优先在 Answer Mode（问答模式）下进行纯粹、详尽、客观的技术回答**。
   - **在用户没有看到并阅读完毕 Agent 回复的完整文字之前，Agent 严禁调用任何写代码工具！**
